## Reporting a Vulnerability

The maintainers take security seriously. If you discover a vulnerability or potential security flaw in **Synthetic Data Studio**, please do not disclose it publicly in an open GitHub issue or discussion forum.

### How to Report

1. Email vulnerability details to the project maintainer or submit a Private Security Advisory via GitHub's [Advisory Reporting Feature](https://github.com/Shivanshm29/synthetic-data-studio/security/advisories/new).
2. Include:
   - Type of vulnerability (e.g. prompt injection, privilege escalation, SSRF, dependency flaw)
   - Step-by-step reproduction instructions or proof-of-concept
   - Potential impact
   - Suggested fix or mitigation (if known)

### Response Timeline

- **Initial Response**: Within 48 hours acknowledging receipt.
- **Triage & Assessment**: Within 7 business days.
- **Fix & Disclosure**: Coordinated release with patch and security advisory.
